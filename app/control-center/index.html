ABOUT

Myanglish

မြန်မာစာကို အင်္ဂလိပ်လက်ကွက်နဲ့ လွယ်ကူစွာ ရိုက်နိုင်စေဖို့ ရည်ရွယ်ပြီး ဖန်တီးထားပါတယ်။

Microsoft Store မှာ တင်ဖို့ ကြိုးစားခဲ့ပေမယ့် certificate signing လိုအပ်နေသေးတဲ့အတွက် publish လုပ်ဖို့ မအောင်မြင်ခဲ့ပါဘူး။ ဒါကြောင့် လက်ရှိ Setup လုပ်တဲ့အချိန်မှာ အခက်အခဲအနည်းငယ် ရှိနိုင်ပါတယ်။

နောက်ပိုင်းမှာ Microsoft Store ပေါ် တင်နိုင်အောင် ဆက်လက်ပြင်ဆင်ပြီး Windows ရဲ့ built-in language/input ရွေးချယ်မှုထဲမှာပါ Myanglish ကို အလွယ်တကူ အသုံးပြုနိုင်တဲ့အဆင့်အထိ develop လုပ်သွားဖို့ ရည်ရွယ်ထားပါတယ်။

Myanglish ပိုကောင်းလာဖို့ အကြံပေးချက်များ၊ လုပ်ဆောင်ချက်အသစ် အကြံပြုချက်များနဲ့ စကားလုံးအကြံပြုချက်များကို ပေးပို့နိုင်ပါတယ်။
