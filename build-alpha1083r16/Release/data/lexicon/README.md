# Burmese Lexicon (alpha-0.3)

`burmese_lexicon.txt` is a deduplicated development lexicon built from the three Burmese lists in the user-supplied "Awesome Myanmar Wordlists Dictionary Collection":

- `mydict-common-words.txt`
- `mydict-mmnlp-words.txt`
- `mydict-syllables.txt`

The merged file contains 44,709 unique non-empty entries.

## How alpha-0.3 uses it

The lexicon validates/ranks generated Burmese candidates and productive no-space prefix candidates. It is **not** a Myanglish-to-Burmese mapping by itself because the source lists contain Burmese words but do not provide a Myanglish spelling for every word.

Words that cannot be generated by the current rules still need an explicit Myanglish mapping (base dictionary, personal dictionary, or a future transliteration/AI suggestion layer).

## Redistribution note

The supplied collection aggregates data from multiple upstream projects and its top-level README does not establish one single license for all entries. Before a public binary release that redistributes this merged lexicon, review the licenses/permissions of the original upstream word lists and include the required notices.
