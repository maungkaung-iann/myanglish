MYANGLISH USER GUIDE

Myanglish က English keyboard နဲ့ Myanglish ရိုက်ပြီး မြန်မာစာအဖြစ် ပြောင်းရေးနိုင်တဲ့ keyboard ဖြစ်ပါတယ်။

ဥပမာ
mingalar → မင်္ဂလာ
kyi → ကြည့်

1. စာရိုက်နည်း
Myanglish keyboard ကိုရွေးပြီး English keyboard နဲ့ Myanglish အတိုင်းရိုက်ပါ။
စာရိုက်နေတုန်း raw Myanglish ကိုပဲမြင်ရပါမယ်။
Space တစ်ချက်နှိပ်ရင် မြန်မာစာအဖြစ်ပြောင်းပါမယ်။

2. Candidate ပြောင်းနည်း
Space ထပ်နှိပ်ရင် နောက် candidate ကိုပြောင်းပေးပါမယ်။
လိုချင်တဲ့စာလုံးရတဲ့အထိ Space နှိပ်ပြီးရွေးနိုင်ပါတယ်။

3. စာလုံးအတည်ပြုနည်း
Enter နှိပ်ပြီး အတည်ပြုနိုင်ပါတယ်။
နောက်စကားလုံးကို စရိုက်ရင်လည်း လက်ရှိရွေးထားတဲ့စာလုံးကို အလိုအလျောက်အတည်ပြုပြီး ဆက်ရိုက်နိုင်ပါတယ်။

4. Backspace
Conversion လုပ်ထားချိန် Backspace နှိပ်ရင် raw Myanglish ကိုပြန်ရပါမယ်။

5. Esc
Conversion ကို cancel လုပ်ပြီး raw Myanglish ကိုပြန်ရပါမယ်။

Shift + Number က English keyboard symbols အတိုင်းဖြစ်ပါတယ်။

7. Special Keys
\ → င်္
Shift + \ → င်

8. Personal Dictionary
Candidate popup အောက်က + Add / manage words... ကိုနှိပ်ပြီး Myanglish spelling နဲ့ Myanmar word ထည့်နိုင်ပါတယ်။
Add Word နဲ့သိမ်းပြီး Delete Selected နဲ့ဖျက်နိုင်ပါတယ်။
