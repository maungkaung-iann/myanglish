Installation Guide

Myanglish Install ပြုလုပ်နည်း

MyanglishInstaller.exe ကို Download လုပ်ပြီး အောက်ပါအဆင့်တွေအတိုင်း တပ်ဆင်နိုင်ပါတယ်။

1
Download

Download for Windows ကိုနှိပ်ပြီး MyanglishInstaller.exe ကို Download လုပ်ပါ။

2
Run Installer

Download ပြီးသွားတဲ့ MyanglishInstaller.exe ကိုနှိပ်ပြီး ဖွင့်ပါ။

3
More info

Windows SmartScreen ပေါ်လာပါက More info ကိုနှိပ်ပါ။

4
Run anyway

Run anyway ကိုနှိပ်ပြီး installer ကို ဆက်ဖွင့်ပါ။

5
Allow Installation

Windows က ခွင့်ပြုချက်တောင်းလာပါက Yes ကိုနှိပ်ပါ။

6
Select Myanglish

တပ်ဆင်ပြီးပါက Win + Space ကိုနှိပ်ပြီး Myanglish ကိုရွေးပါ။ ပြီးရင် Myanglish နဲ့ ချက်ချင်း စတင်ရိုက်နိုင်ပါပြီ။

Why does this appear?

လက်ရှိ MyanglishInstaller.exe ကို commercial code-signing certificate ဖြင့် sign မလုပ်ရသေးတဲ့အတွက် Windows SmartScreen က Unknown publisher အဖြစ် သတိပေးချက်ပြနိုင်ပါတယ်။ ဒီအခြေအနေကို နောက်ပိုင်း release များမှာ ပိုကောင်းအောင် ပြင်ဆင်သွားဖို့ စီစဉ်ထားပါတယ်။

Features

Myanglish ရဲ့ အဓိကလုပ်ဆောင်ချက်များ

01
Myanglish Typing

English keyboard ကိုအသုံးပြုပြီး ရင်းနှီးပြီးသား Myanglish ပုံစံနဲ့ မြန်မာစာရိုက်နိုင်ပါတယ်။

02
Candidate Selection

Space ကို တစ်ချက်နှိပ်ပြီး ပထမ candidate ကို ရွေးချယ်နိုင်ပါတယ်။

03
Multiple Candidates

Space ကို ထပ်နှိပ်ပြီး အခြား candidate စကားလုံးတွေကို တစ်ခုပြီးတစ်ခု ရွေးချယ်နိုင်ပါတယ်။

04
Quick Commit

ရွေးထားတဲ့စကားလုံးနောက် စာဆက်ရိုက်လိုက်တာနဲ့ လက်ရှိစကားလုံးကို အလိုအလျောက် အတည်ပြုပေးပါတယ်။

05
English Inside Burmese

မြန်မာစာရိုက်နေစဉ် လိုအပ်တဲ့ English စကားလုံးတွေကိုလည်း ထည့်သွင်းရိုက်နိုင်ပါတယ်။

06
Myanmar Punctuation

အသုံးများတဲ့ punctuation တွေကို မြန်မာစာရေးသားမှုနဲ့ ကိုက်ညီအောင် အသုံးပြုနိုင်ပါတယ်။

07
Fast Language Switching

Win + Space ကနေ Myanglish ကို လွယ်ကူစွာ ရွေးချယ်အသုံးပြုနိုင်ပါတယ်။

08
Familiar Keyboard

Keyboard layout အသစ်ကို အစကနေ အလွတ်ကျက်စရာမလိုဘဲ English keyboard ပေါ်မှာပဲ Myanglish နဲ့ ရိုက်နိုင်ပါတယ်။
