Download for Windows
Windows 11 · x64 · Version 1.0.11

တပ်ဆင်နည်း

1. Download for Windows ကိုနှိပ်ပြီး MyanglishInstaller.exe ကို Download လုပ်ပါ။
2. Download ပြီးသွားတဲ့ MyanglishInstaller.exe ကို နှစ်ချက်နှိပ်ပြီး ဖွင့်ပါ။
3. Windows က ခွင့်ပြုချက်တောင်းလာပါက Yes ကိုနှိပ်ပါ။
4. တပ်ဆင်ပြီးပါက Win + Space နှိပ်ပြီး Myanglish ကိုရွေးပါ။
Space စကားလုံးကို မြန်မာလိုပြောင်းရန်
Space ×2 အခြားစကားလုံးများကို ကြည့်ရန်
ဆက်ရိုက်ခြင်း စကားလုံးရွေးပြီးနောက် နောက်စာလုံးကို ဆက်ရိုက်ရုံဖြင့် ရွေးထားသောစကားလုံးကို အလိုအလျောက် အတည်ပြုပေးပါမယ်။
