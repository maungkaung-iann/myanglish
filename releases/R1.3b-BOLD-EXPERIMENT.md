# Myanglish Alpha 0.10.8.3R1.3b — Bold Candidate Indicator

Base: **R1.3a confirmed stable**.

Only candidate-indicator presentation is changed.

R1.3a:
- candidate exists -> bold underline
- no candidate -> no underline

R1.3b:
- candidate exists -> raw Myanglish visually bold
- no candidate -> normal raw Myanglish
- no underline indicator

Implementation note: Windows TSF does not expose a portable inline font-weight=Bold field. R1.3b therefore uses a click-through/no-activate visual overlay aligned to the TSF composition rectangle. Document text and R1.3a conversion/state logic are unchanged.

Protected: Backspace, Left/Right auto-commit, unknown-word+Space, Add/manage words, candidate cycling, mappings, digits/symbols, Note preview.
